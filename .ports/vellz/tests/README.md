# Tests and fixtures

## Scene corpus

`tests/scenes/*.json` is the single source of truth for differential tests.
The same files are rendered by:

- the upstream oracle (`tools/oracle-rs`, pinned `vello_cpu`), and
- vellz (the Zig CLI, once the corresponding feature is implemented).

Scene construction, transforms, colors, and settings therefore cannot drift
between the two implementations.

## Fixtures

`tests/fixtures/oracle/` contains, per scene:

- `<name>.rgba` — raw premultiplied sRGB RGBA8 pixels (exact comparison),
- `<name>.json` — metadata written by the oracle: dimensions, pipeline
  settings, pinned revision, and FNV-1a hashes of scene and output,
- `<name>.png` — optional human-readable preview (never used for comparison).

Fixtures are generated by the pinned upstream revision:

```sh
tools/fetch-reference.sh
cd .reference/vello && cargo build --release -p vello_toy && cd ../..
tools/render_corpus.sh --png          # regenerate + double-render determinism check
tools/render_corpus.sh --check        # verify committed fixtures without writing
```

Provenance: the scenes are original to this repository; the oracle outputs are
produced by code from <https://github.com/linebender/vello> at
`1e63b4a40ccb484f82e1d85b83df97ab95bcfbe83` (Apache-2.0 OR MIT). Upstream test
assets later imported as fixtures keep their own license files alongside them.

## Comparison policy

`tools/compare.py` reports exact mismatches, per-channel statistics, and a diff
image. The default is exact equality. A tolerance is allowed only when a
documented algorithmic difference exists (for example a different SIMD
reduction order) and must state:

- the fixture and the compared backends,
- the metric and threshold,
- why exact equality is not achievable.

Tolerances never mask missing geometry: a scene whose feature is unimplemented
must fail loudly or be absent from the corpus, not produce approximate output.

## Upstream probe fixture

`tests/fixtures/upstream/probe.rgba` is the pinned upstream probe reference
(`vello_common/assets/probe.rgba`, 51×51 unpremultiplied RGBA8, imported
byte-for-byte; see the fixture README). The scene is ported in
`src/common/probe.zig` (8 active elements; upstream's `Filter` element is
disabled) and rendered by `vellz.cpu.probe.renderProbePixmap` at the exact
reference settings (`Level.fallback`, 0 threads, `RenderMode.optimize_quality`,
`TargetInit.clear(css.WHITE)`).

```sh
zig build probe      # tools/check_probe.sh: render + compare
```

Policy: upstream's probe comparison uses a per-channel absolute tolerance of 3
on all four channels (pixels where both alphas are zero compare equal). That
tolerance is imported with the fixture and never used to hide missing
geometry; the vellz f32/scalar path is byte-exact, and both the CLI and
`tools/compare_raw.py` report the measured maximum channel difference. The
same comparison also runs inside `zig build test` through the embedded
fixture.

## Covered areas (current and planned)

| Area | Scene |
| --- | --- |
| empty scene | `empty_64` |
| antialiased solid fill | `fill_rect_64` |
| translucent overlap | `fill_overlap_alpha_64` |
| winding rules | `fill_path_evenodd_64`, `fill_path_nonzero_64` |
| transforms | `transform_rotate_64` |
| nested clipping | `clip_nested_64` |
| isolated clip layer | `clip_layer_64` |
| strokes | `stroke_basic_64` |
| degenerate geometry | `degenerate_64` |
| tile seams / wide curvature | `fill_wave_seams_128`, `fill_tile_grid_128` |
| linear / radial / sweep gradients | `gradient_linear_64`, `gradient_radial_64`, `gradient_sweep_64` |
| gradient LUT + repeat extend | `gradient_repeat_128` |
| image sampling: nearest, bilinear + reflect | `image_nearest_64`, `image_bilinear_64` |
| blend layer (multiply) | `layer_blend_multiply_64` |
| nested opacity layers | `layer_opacity_64` |
| alpha / luminance masks | `mask_alpha_64`, `mask_luminance_64` |
| upstream probe fixture | `tools/check_probe.sh` (`zig build probe`, embedded in `zig build test`) |

All scenes above render byte-exact with `zig build corpus` (22/22,
`tolerance=0`). Filter layers and blurred rounded rectangles are the remaining
M2 features; their scenes will be added here together with oracle support, and
until then the renderer fails those commands loudly instead of approximating
their output.

Planned: filters, positioned glyphs, mixed scripts, resource exhaustion,
repeated resize.
